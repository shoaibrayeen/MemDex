# What gets embedded

The vector covers the title and breadcrumb as well as the body. A question like
"how do I run the tests" matches the title "Testing" far more strongly than
anything in its body, and leaving the title out measurably hurt retrieval — it
ranked an unrelated memory that merely mentioned `_test.go` above the real one.
